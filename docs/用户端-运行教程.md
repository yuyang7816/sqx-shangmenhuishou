# 用户端运行教程

按顺序做。这是给手机和网页用的应用，应用名称是「上门回收」。用 HBuilderX 打开 `shangmenhuishou-user` 文件夹来运行。

先按 [服务端运行教程](服务端-运行教程.md) 准备好 `smhs` 库并启动服务端。首页上的分类与回收项目来自后台数据。服务端没启动时，页面也许能打开，但列表是空的，登录会失败。

师傅端运行见文末 **附录：师傅端运行**。

## 开始之前要准备什么

安装 HBuilderX：https://www.dcloud.io/hbuilderx.html

下载「正式版」。解压或安装后，打开软件，窗口标题是 HBuilderX，就说明安装成功。

只在电脑浏览器里看时，不需要微信开发者工具。要在微信里看，再安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 第 1 步：确认连的是自己电脑上的服务端

用 HBuilderX 或记事本打开 `shangmenhuishou-user/common/config.js`。文件最上面现在指向线上域名，例如：

```javascript
const ROOTPATH = "https://smhs.xianmxkj.com/sqx_fast";
const ROOTPATH3 = "https://smhs.xianmxkj.com/sqx_fast";
```

改成：

```javascript
const ROOTPATH = "http://127.0.0.1:9692/sqx_fast";
const ROOTPATH3 = "http://127.0.0.1:9692/sqx_fast";
```

两行都要改。`ROOTPATH` / `ROOTPATH3` 是接口地址。保存文件。

如果本机用局域网 IP 调试手机真机，把 `127.0.0.1` 换成你电脑的局域网 IP，例如 `192.168.0.123`，并保证手机和电脑在同一网段。

## 第 2 步：用 HBuilderX 打开项目

1. 打开 HBuilderX。
2. 菜单选「文件」→「打开目录」。
3. 选中 `shangmenhuishou-user` 这个文件夹。不要选它的上一级（那一层还有 `shangmenhuishou-server` 等），也不要只选里面的某个页面。
4. 左侧能看到 `pages`、`pages.json`、`manifest.json`、`common`。

如果这个文件夹里还没有 `node_modules`，在 `shangmenhuishou-user` 里先执行一次 `npm install`。

## 第 3 步：在电脑浏览器里运行

1. 菜单选「运行」→「运行到浏览器」→「Chrome」。没有 Chrome 时选 Edge。
2. 第一次会下载编译器，底部控制台会出现「正在编译」。等到出现「编译成功」，浏览器会自己打开。
3. 地址以控制台里打印的为准。如果控制台里写的是别的端口，用控制台里的地址。
4. 打开后全局标题是「上门回收」，底部应能看到 **首页、订单、我的**。

HBuilderX 不要关。关掉后页面会打不开。

## 第 4 步：在微信小程序里运行（可选）

电脑浏览器已经能看，可以先不做这一步。

1. 安装并打开一次微信开发者工具，用微信扫码登录。
2. 在微信开发者工具里打开「设置」→「安全设置」，打开服务端口。
3. 回到 HBuilderX，菜单「工具」→「设置」→「运行配置」，把微信开发者工具的安装路径填上。
4. 菜单「运行」→「运行到小程序模拟器」→「微信开发者工具」。

`manifest.json` 里 `mp-weixin` → `appid` 已经写了一个小程序号码。那是原项目的号码。你不是该小程序的开发成员时，微信会提示 AppID 没有权限。自己练习时，把这个 `appid` 改成你自己的小程序 AppID，或继续只用浏览器运行。

微信开发者工具里如果提示域名不合法，本地调试可以勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。`127.0.0.1` 不是微信后台配置过的合法域名，不勾选这一项，模拟器里的接口会失败。

## 怎样算成功

首页能打开，底部三个按钮能点。按键盘 `F12`，点「网络」或 Network，再按一次浏览器的刷新。列表里的请求地址应是 `127.0.0.1:9692`。出现线上域名（例如 `smhs.xianmxkj.com`），说明第 1 步没有保存，或改完后没有重新点「运行到浏览器」。

若后台还没有配置分类与回收项目，首页可能是空的。这表示接口已经通了，只是还没有业务数据。先到管理端维护分类 / 项目 / 价格，再回来看。

用手机号注册需要短信。短信密钥没配时，验证码发不出去。密钥申请见 [用户端功能说明](用户端-功能说明.md) 末尾。

## 常见问题

**首页空白、登录失败**  
服务端没启动，或 `common/config.js` 还指向线上。按第 1 步改成本机 `9692`。

**小程序里接口全失败**  
勾选「不校验合法域名」；或把接口地址改成可被手机访问的局域网 IP。

**要测完整预约回收**  
需要：管理端有分类与项目 → 用户端能登录并下单 → 师傅端能抢单并完成（线下结算）。

用户端能做什么，见 [用户端功能说明](用户端-功能说明.md)。服务端与管理端见 [服务端运行教程](服务端-运行教程.md)、[管理端运行教程](管理端-运行教程.md)。

## 附录：师傅端运行

师傅端代码在 `shangmenhuishou-shop`，应用名称是「上门回收师傅端」。底部两个入口：**回收池、我的**。

1. 用 HBuilderX 打开 `shangmenhuishou-shop`（不要选错成用户端目录）。
2. 打开 `shangmenhuishou-shop/common/config.js`，把线上地址改成本机，例如：

```javascript
const ROOTPATH = "http://127.0.0.1:9692/sqx_fast";
const ROOTPATH3 = "http://127.0.0.1:9692/sqx_fast";
```

真机调试时同样改成局域网 IP。

3. 「运行到浏览器」或「运行到微信开发者工具」。成功标志：底部能看到 **回收池、我的**，且 Network 请求指向本机 `9692`。
4. 小程序 AppId 见 `shangmenhuishou-shop/manifest.json` 的 `mp-weixin.appid`，练习时请改成自己的。

师傅端能力说明见 [用户端功能说明](用户端-功能说明.md) 中的「师傅端」章节。
