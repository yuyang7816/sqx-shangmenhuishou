# 服务端运行教程

按顺序做。做完一步，看到文中写的成功标志，再做下一步。

服务端是四端里要第一个启动的。代码在 `shangmenhuishou-server` 文件夹。这是一个 Maven 多模块工程，真正可运行的模块是 `sqx-application`，启动类是 `com.sqx.SqxApplication`。数据库不用自己建表，项目里已经带了一份导出文件：`shangmenhuishou-server/db/smhs.sql`。

## 开始之前要准备什么

在自己的 Windows 电脑上安装下面三个软件。安装时勾选「添加到 PATH」或「Add to PATH」。

| 软件 | 用什么版本 | 怎样确认已经装好 |
|---|---|---|
| JDK | 1.8（也叫 Java 8） | 开始菜单打开「命令提示符」或 PowerShell，输入 `java -version`，能看到 `1.8.0` |
| Maven | 3.6 或更高 | 输入 `mvn -v`，能看到 `Apache Maven 3` |
| MySQL | 5.7 或 8.0 | 开始菜单里能找到「MySQL Command Line Client」或「MySQL 8.0 Command Line Client」 |

Java 不要装成 11、17 或 21。装错版本时，先卸掉，再装 1.8。下载可用 Adoptium 的 Temurin 8：https://adoptium.net/temurin/releases/?version=8

Maven 下载：https://maven.apache.org/download.cgi 。解压后把里面的 `bin` 文件夹加到 PATH。关掉原来的 PowerShell，再打开一个新的，`mvn -v` 才能看到版本。

MySQL 安装过程中会让你给 `root` 设一个密码，还会让你确认端口。把密码和端口记下来。Windows 上新装的 MySQL，端口通常是 **3306**。开发配置里写的也是 **3306**，密码写的是 `123456`。这是这份配置自己的默认值，和你安装时设的不一定相同。后面要把配置改成和你电脑一致。

Redis 当前是关着的。打开 `shangmenhuishou-server/sqx-application/src/main/resources/application.yml`，`sqx.redis.open` 和 `sqx.shiro.redis` 都是 `false`。按本教程启动时，不必先装 Redis。以后如果把这两个开关改成 `true`，再安装 Redis，地址用 `localhost`，端口 `6379`（见 `application-dev.yml` 里的 `redisson` 配置）。

## 第 1 步：新建空数据库

1. 打开开始菜单里的 MySQL 命令行。
2. 输入你安装 MySQL 时设的 root 密码，回车。看到 `mysql>` 才算连上。
3. 把下面这一整行复制进去，回车：

```sql
CREATE DATABASE IF NOT EXISTS `smhs` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

4. 再输入：

```sql
SHOW DATABASES;
```

列表里有 `smhs` 就成功了。输入 `exit` 退出。

如果提示 `Access denied`，是密码错了，用安装 MySQL 时设的那个密码重来。

## 第 2 步：导入项目里的数据库文件

文件位置（相对整个项目文件夹）：

`shangmenhuishou-server/db/smhs.sql`

这是演示库。里面有菜单、角色、系统配置项、帮助协议、废品分类 / 项目 / 价格等初始化数据；用户、订单、支付、提现、聊天等业务隐私数据已清空；客服微信、支付、短信、OSS、地图、小程序等密钥也已清空。导入会覆盖同名的表，所以请导入到上一步新建的空库，不要导入到别的业务库。

在项目根目录打开 PowerShell。把 `-p` 后面的密码、`-P` 后面的端口，改成你的 MySQL。下面这个例子按配置文件的默认值来写：密码 `123456`，端口 `3306`。

```powershell
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
& $mysql -uroot -p123456 -P3306 --default-character-set=utf8mb4 smhs -e "source $($PWD.Path -replace '\\','/')/shangmenhuishou-server/db/smhs.sql"
```

执行时窗口会停一会儿。结束时没有 `ERROR`，再执行下面这句，能看到很多表名，就说明导入成功：

```powershell
& $mysql -uroot -p123456 -P3306 --default-character-set=utf8mb4 -e "USE \`smhs\`; SHOW TABLES;"
```

如果提示找不到 `mysql.exe`，到 `C:\Program Files\MySQL\` 下面找到实际的 `mysql.exe`。装的是 5.7 时，路径里通常是 `MySQL Server 5.7`。把上面第一行的路径换成你的路径。

用 Navicat 也可以：连接到本机 MySQL，双击打开 `smhs`，菜单选「运行 SQL 文件」，选中 `shangmenhuishou-server/db/smhs.sql`，编码选 UTF-8，点开始。底部显示成功即可。

## 第 3 步：让程序连接你自己的 MySQL

服务端默认激活的是 **prod** 配置。本地开发建议改成 **dev**。

### 3.1 改激活环境

打开：

`shangmenhuishou-server/sqx-application/src/main/resources/application.yml`

找到：

```yaml
spring:
  profiles:
    active: prod
```

改成：

```yaml
spring:
  profiles:
    active: dev
```

也可以不改文件，启动时指定：`--spring.profiles.active=dev`。

### 3.2 改数据库账号密码

打开：

`shangmenhuishou-server/sqx-application/src/main/resources/application-dev.yml`

找到这三行：

```yaml
url: jdbc:mysql://127.0.0.1:3306/smhs?useUnicode=true&characterEncoding=utf-8&useSSL=false
username: root
password: 123456
```

地址保持 `127.0.0.1`，库名保持 `smhs`。只改端口和密码：

- 你的 MySQL 端口不是 3306 时，把 `3306` 改成你的端口。
- `password` 改成你安装 MySQL 时设的密码。已经是 `123456` 就不要改。

保存。

## 第 4 步：启动服务端

在 `shangmenhuishou-server` 文件夹里打开 PowerShell（在文件夹空白处按住 Shift，右键，选「在此处打开 PowerShell 窗口」或「在终端中打开」），执行：

```powershell
mvn clean install -DskipTests
mvn spring-boot:run -pl sqx-application
```

第一次会下载很多依赖，可能要 10 到 30 分钟，窗口要一直开着。看到 Spring Boot 正常启动、没有数据库连接错误，并且端口 **9692** 已监听，才算成功。

不要关闭这个窗口。关闭后服务端就停了。

用 IDEA 也可以：

1. 用 IDEA 打开 `shangmenhuishou-server`（选有父级 `pom.xml` 的那一层）。
2. Project SDK 选 **1.8**。
3. 安装 Lombok 插件，并打开 Annotation Processing。
4. 运行 `com.sqx.SqxApplication`。

## 怎样算成功

浏览器打开：

http://127.0.0.1:9692/sqx_fast/doc.html

能看到 Knife4j / OpenAPI3 接口文档页面，就说明服务端已经起来了。所有接口都在 `/sqx_fast` 下面，端口是 **9692**。

管理端演示账号以你导入的库数据为准（常见为 **admin** / **123456**，导入后请立即修改）。用户端 / 师傅端需要自己注册，或配好微信后再登录。

## 常见问题

**启动后立刻报数据库连不上**  
核对第 3 步的端口、密码，以及 `spring.profiles.active` 是否已改成 `dev`。确认第 1、2 步已经建好 `smhs` 并导入了表数据。

**Java 版本不对**  
`java -version` 必须是 1.8。装了多个 JDK 时，IDEA 的 Project SDK 也要选 1.8。

**Redis 相关报错**  
确认 `application.yml` 里 `sqx.redis.open` 和 `sqx.shiro.redis` 都是 `false`。本教程不要求启动 Redis。

短信、微信、支付宝、对象存储、地图等密钥，演示库已清空。只把服务端跑起来，这些外部能力不会自动可用。申请后请在管理端「系统配置」中填写。服务端能做什么，见 [服务端功能说明](服务端-功能说明.md)。
