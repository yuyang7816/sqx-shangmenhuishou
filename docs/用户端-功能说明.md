# 用户端 / 师傅端功能说明

本文说明两个 uni-app 端：

- **用户端**（`shangmenhuishou-user`）：应用名称「上门回收」，底部 **首页、订单、我的**
- **师傅端**（`shangmenhuishou-shop`）：应用名称「上门回收师傅端」，底部 **回收池、我的**

界面组件库均为 **uView Plus**（约 3.3.x）。平台工作人员使用电脑上的管理端，不使用这两个 App。

---

## 一、用户端

### 这个端是给谁用的

- **消费者**：选城市、看回收分类与价格、预约上门、管理地址与订单、邀请好友、申请成为回收员入口。
- **平台工作人员不使用这个应用。** 审核订单、改轮播、管分类价格与系统配置，在电脑上的管理端做。

### 首页

打开就是首页（`pages/index/index`）。

- **选城市**：进入城市页（`pages/index/citys/citys`）。
- **轮播与分类**：宣传图与回收分类入口，内容来自管理端配置。
- **回收项目 / 详情**：浏览可回收项目与价格，进入详情（`pages/index/detail`）后可走预约。
- **搜索**：分包 `my/search/index`。

核心回收路径：

**选分类 / 项目 → 填地址与预约时间 → 下单待接单 → 师傅上门服务 → 线下结算完成**

预约填写页在 `my/order/orderDet`、`my/order/editor`。

### 订单

底部「订单」（`pages/order/index`）：

- 查看自己的预约订单列表（可按状态筛选，与服务端状态一致）。
- 进入订单详情（`my/order/detail`）。
- 待接单等允许取消的状态可取消订单。

订单数据存在自己的服务器里，不是微信订单中心。结算多为线下完成，不依赖用户在线支付废品货款。

### 登录、注册和找回密码

登录相关页面在 `pages/public`：

- **微信登录**：小程序里常用。要配好小程序 AppId 和密钥。
- **手机号 + 密码登录**（`loginphone`）。
- **注册**：手机号、短信验证码、密码。验证码是服务端发出的短信。
- **忘记密码**：改密码同样要短信验证码。

没配短信密钥，或短信签名没审核通过时，验证码发不出去，就无法用验证码注册。这时页面会停在发送失败，不是网络坏了。

### 我的

未登录时，头像旁边是「登录」。登录后显示昵称等信息（`pages/my/index`）。

常见入口：

| 入口 | 做什么 |
|---|---|
| 个人信息 | 修改资料（`pages/my/userinfo`） |
| 我的地址 | 地址列表与新增（`my/address`） |
| 邀请好友 | 邀请关系 / 分享（`pages/my/invitationUser`） |
| 招募回收员 | 入驻招募入口（`my/other/work`） |
| 消息中心 | 站内消息（`my/message/index`） |
| 客服 / 帮助 / 协议 | 客服、帮助中心、隐私政策、用户协议 |
| 设置中心 | 意见反馈、注销、关于我们、退出登录等 |

注销是提交注销申请，不是点一下账号立刻从数据库消失。

## 二、师傅端

### 这个端是给谁用的

- **回收员**：看接单池、抢单、上门服务、完成订单；实名认证；缴纳保证金；钱包提现。
- **消费者不使用这个应用。**

师傅履约路径：

**认证入驻 →（可选）缴保证金 → 抢单 → 开始服务 → 完成订单**

### 回收池

底部「回收池」（`pages/index/index`）：

- 按城市查看待接单池。
- 抢单后进入接单详情（`my/order/takeDetail`）。
- 可开始服务、完成订单，或取消 / 停止服务（以页面按钮与接口为准）。
- 已接订单详情见 `my/order/detail`。

订单状态与服务端一致：待接单 → 待服务 → 进行中 → 已完成 / 已取消。

### 我的

常见入口（`pages/my/index` 及分包）：

| 入口 | 做什么 |
|---|---|
| 实名认证 | 提交认证资料（`my/renzheng/index`） |
| 我的钱包 | 余额与入口（`my/wallet/index`） |
| 提现 / 提现账号 / 提现记录 | 申请提现与绑定收款账号 |
| 保证金 / 保证金明细 | 缴纳与查看保证金记录 |
| 钱包明细 | 资金流水 |
| 消息中心 | 站内消息 |
| 设置中心 | 协议、反馈、注销、关于我们等 |

提现只生成待审核记录，真正打款在管理端审核后处理。保证金等支付依赖后台已配置微信 / 支付宝密钥。

---

## 三、这两个端真正会连到外面的服务

短信、微信、支付宝、图片存储、地图的密钥填在管理端「系统配置」，由服务端去调用。只改 App 页面上的字，不会变成已经开通。

| 能力 | 什么时候用到 | 没配好会怎样 |
|---|---|---|
| 短信 | 注册、找回密码 | 验证码发不出去 |
| 微信支付 / 支付宝 | 保证金等支付场景 | 无法拉起付款 |
| 对象存储 / 文件上传 | 头像、认证材料等上传 | 上传失败 |
| 微信小程序登录 | 小程序登录 | 登录失败 |
| 地图选点 | 填写上门地址等 | 可能只能手填地址 |

## 这些是站内能力

- 首页轮播、分类、回收项目与价格展示
- 预约下单、接单池、订单列表和详情（不含第三方支付本身）
- 邀请关系展示
- 帮助文章、协议正文
- 提现申请本身（打款在管理端审核后处理）
- 订单状态流转与线下结算记账
