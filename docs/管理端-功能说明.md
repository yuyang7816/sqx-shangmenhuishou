# 管理端功能说明

管理端是给平台工作人员用的网站，在电脑浏览器里打开。消费者和回收员不使用这个网站。它用来看经营数据、管用户与回收订单、处理师傅认证与财务，以及填写微信、支付宝、短信、图片存储这些外面服务的账号。

程序里的名称是「省钱兄上门回收系统」（见 `src/utils/httpRequest.js` 中的 `entryName`）。工作人员登录后，左侧是菜单。能看到哪些菜单，由管理员给这个账号分配的权限决定。没有权限的菜单不会出现。

下面的菜单名称来自 `src/views` 常见业务页面。如果你后来在「菜单管理」里改过名字，以你屏幕上看到的为准。

## 登录

登录页（`src/views/common/login.vue`）要填账号、密码，还要看一张图片验证码。看不清就点图片换一张。验证码由服务端生成。服务端没启动时，图片是裂的，登录也会失败。

演示账号以导入库中数据为准，常见为 `admin` / `123456`。导入后请立即修改。

## 登录之后第一眼：首页

登录后的首页（`src/views/common/home.vue`）用来看平台概况。数字来自自己的数据库，不连接外面的报表公司。

它用来知道有没有新订单、师傅与用户动态，不是在这里替用户下单。

## 订单中心（orderCenter）

| 页面 | 用途 |
|---|---|
| `orderCenter.vue` | 回收预约订单列表，可按状态筛选 |
| `orderDetails.vue` | 订单详情，核对地址、项目、师傅与状态 |

订单状态与服务端一致：待接单 → 待服务 → 进行中 → 已完成 / 已取消。真正履约由师傅端完成；本页主要是运营查看与必要时干预。

## 本地业务 / 废品配置（locality）

| 页面 | 用途 |
|---|---|
| `classification.vue` | 废品分类 |
| `specifications.vue` / `locality.vue` | 回收项目、规格等相关维护 |
| `materialLink.vue` | 素材 / 内容关联 |

用户端首页看到的分类、项目与价格，依赖这里（及价格相关后台配置）维护好的数据。

## 师傅相关（masterWorker）

| 页面 | 用途 |
|---|---|
| `masterWorker.vue` | 师傅列表 |
| `masterWorkerDatas.vue` | 师傅数据统计 |
| `masterWorkerWallet.vue` | 师傅钱包相关 |
| `masterPosition.vue` | 师傅位置相关展示（地图） |

## 认证 / 招募（autonym）

| 页面 | 用途 |
|---|---|
| `autonym.vue` / `autonymPeople.vue` | 个人认证、招募审核等 |

师傅在 App 提交实名或招募资料后，记录出现在这里，由人工审核。

## 财务（finance）

`financeList.vue` 等财务列表：提现申请、资金相关记录。有权限时可以审核提现。

用户 / 师傅提现通过，只表示平台同意打款。是否再走支付宝转账一类操作，取决于你是否配了支付密钥，以及当时选的打款方式。系统不会在用户一点「提现」时就自动把钱打出去。

## 首页装修与轮播（fitment / banner）

| 页面 | 用途 |
|---|---|
| `fitmentList.vue` | 首页装修相关配置 |
| `bannerList.vue` | 轮播图 |

改完保存后，用户下次打开首页才会变。回收项目本身不在轮播页里写死，项目来自分类 / 项目维护。

## 用户（user）

| 页面 | 用途 |
|---|---|
| `userList.vue` | App 用户列表 |
| `userDetail.vue` 等 | 用户详情 |

可按手机号等条件查看用户。注销申请等另有对应管理入口（以菜单权限为准）。

## 消息与反馈

查看站内消息、用户意见反馈一类记录。用户在手机「意见反馈」入口提交后，会出现在这里。这不是手机短信。短信要走「系统配置」里的短信服务商。

## 系统配置：外面那些服务的账号都在这里

这是和第三方关系最大的一页。短信、微信支付、支付宝、图片存到哪一家、地图等，都在「系统配置」里改。

改完要保存。用户端 / 师傅端下次请求才会用新的密钥。只在 App 端改文字，不会变成已经开通了支付。

常见需要自己申请的能力：

- **短信**：腾讯云 / 阿里云 / 短信宝等
- **微信支付、支付宝**（保证金等场景）
- **对象存储**：阿里云 OSS 等，或本地存储
- **微信小程序 AppId**（用户端 / 师傅端）
- **地图**（地址选点、师傅位置等）

缺一项，对应功能会在 App 端失败，而不是后台假装成功。

## 系统管理

「系统管理」是给工作人员账号用的，消费者看不到（页面多在 `src/views/modules/sys`）：

- **管理员管理**：后台登录账号。可以新增工作人员。
- **角色管理**：一组权限的名字，例如只让某个人看订单、不能改财务。
- **菜单管理**：左侧有哪些菜单。改错了可能导致某个页面从菜单里消失。

## 和其他端的关系

- 管理端维护分类、项目、价格、轮播，用户端才会有可预约内容。
- 管理端审核认证 / 招募，师傅才能正常接单履约。
- 管理端审核提现与保证金相关记录，App 端对应状态才会变化。
- 支付、短信、存储密钥只配在服务端能读到的系统配置里。
